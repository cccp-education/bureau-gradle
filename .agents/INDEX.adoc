== Vision — Bureau de l'apprenant

*bureau-gradle* est le point d'entrée CLI/Docker de l'apprenant pour
l'écosystème education.ccp. Surnom : *Saint-Denis* (93, France).

3 rôles :
. **Create office** — scaffold `office/` (AsciiDoc pivot, git repo)
. **Create items** — invoque les outils OSS (capsule, slider, document,
  plantuml, bakery, planner, codebase, etc.)
. **Consume training** — pull matériel pédagogique versionné (git)

Open core : bureau-gradle (OSS) + workspace-gradle (privé, runtime
agentique FormationRuntimePort pour edster.cloud).

*Vision* : `foundry/private/workspace-gradle/.agents/VISION_FORMATION_INTERACTIVE.adoc`
*Cadrage* : `CADRAGE_EPIC_RUNTIME_AGENTIQUE.adoc` (racine workspace, 12e document jardin secret)
